骑士剑当前内容见[武器描述与故事整合稿](weapons/knightsword-stories.md)，已覆盖基础剑至最后的黎明的九个阶段，并接入工坊、背包与市场的阅读窗口。每阶分别保存中英武器描述、故事片段和参考图链接，英文故事按中文段落对应；后续修订直接编辑该 MD，前端按界面语言读取对应正文。此稿不采用“黄金律法”设定，旧传说和分件框架供创作对照。

刺剑当前内容见[八阶武器描述与故事](weapons/rapier-stories.md)，同样保存中英正文并接入阅读窗口。故事从普通女孩习武、入团与受封开始，与骑士剑共享北境失守和王都守城，随后护送平民、书籍与匠人穿越山口。两条线以少量共同经历回应青梅关系，最后一战的结果仍未写定。

大剑当前内容见[六阶武器描述与故事](weapons/greatsword-stories.md)，保存中英正文并接入阅读窗口。以矿镇守路、古炉开采、龙骸异化与统治扩张为线索，从暴君一侧回应石桥断后、渡口夜袭、王都守城和最后的白剑。各共同事件与另外两条路线保持一致，胜负继续留白。

## 核心主题

> 君王以一己之力带来黑暗，骑士以万千牺牲换取黎明。

魔王剑象征绝对力量，骑士剑象征凡人的集体意志。魔王只需要一把剑就能统治王国，而无数骑士的佩剑、生命与被抹去的名字，才共同铸成一把足以与其抗衡的圣剑。

力量与牺牲都不能单独证明持有者的正当性。暴君的扩张、王庭未曾回应的求援以及最后一战的结果，都可由不同立场的记述继续补充。当前三份整合稿不采用“黄金律法”设定。

与主力骑士团迎向深渊的使命并行，绯翼骑士团承担让幸存者与文明得以延续的责任。她们有勇气离开最后的战场，也有责任活着将希望带往远方。庇护与传承使刺剑形成独立主线，并与统治、献身两条路线回应同一场灾难。

| 武器路线 | 核心理念 | 最终象征 |
|---|---|---|
| 熔核重剑 | 统治与力量 | 余烬君王：黑暗的降临 |
| 骑士剑 | 荣耀与献身 | 最后的黎明：为终结黑暗而牺牲 |
| 刺剑 | 庇护与传承 | 炽翼天使：为延续文明而守望 |

## 叙事基调

古老、庄严、悲壮。借鉴《艾尔登法环》《黑暗之魂》中通过残缺记述与遗物呈现历史的叙事气质，以本游戏的黄金王庭、无名骑士、龙骸巨剑与誓约圣剑展开故事。

- 让材质、磨损、纹章、铭文和缺失的名字承担叙事。先让玩家看见遗物，再让他们怀疑遗物的来历。
- 区分人物相信的事情、传说声称的事情与创作层面已确定的设定。单件武器的描述不自动成为全知史书。
- 使用克制的情绪，让牺牲通过具体事物留下痕迹；保留沉默与空白。
- 允许不同来源彼此抵牾，但每一种记述都应有其立场、用途或能够被观察到的依据。
- 三条路线前期各自成立，越接近高阶越能发现同一场王庭覆灭留下的不同选择：主力骑士团迎击黑暗，绯翼骑士团护送幸存者。具体人物、旅途与结局仍通过后续独立故事逐步揭示。

## 留待后续决定的问题

1. 余烬君王是古龙、凡人君主，还是后来者对某种力量的称呼？
2. 他为何摧毁黄金王庭？黄金律法又曾保护、排斥或牺牲过谁？
3. 从荣誉碑上抹去名字，是骑士自愿的誓约，还是律法的一部分？
4. 最后骑士的身份、两把剑的相遇，以及黎明出现的原因，分别有哪些不同版本？
5. 深渊尽头留下武器的究竟是谁？两位持剑者是否真正死去？
6. 玩家锻造的是遗物本体、后世仿作，还是由旧剑重铸的器物？强化与历史记忆之间有何关系？
7. 绯翼骑士团具体护送了谁、保存了哪些知识，又经历了怎样的道路？哪些人最终抵达远方？
8. 天使羽翼是否仅是庇护的象征？圣石的力量来自何处？

这些问题目前保留空白。后续武器故事可以增加证据与解释，但不宜在第一件词条中一次性给出完整答案。

## 单件武器故事的后续写法

`weapons/` 已按路线与模型阶段建立 22 份基础框架，例如 [精铁骑士剑](weapons/knightsword-10.md)、[铁匠大剑](weapons/greatsword-10.md)、[精铁刺剑](weapons/rapier-5.md)。每份记录正式中英文名称、路线与阶段 ID、模型和参考图、阶段定位、命名含义及介绍基调；后续直接在对应文件中继续写正式词条与独立故事。

“+90 沿用 +80 最后的黎明”已于 2026-10-26 落实到游戏配置，并同步 [骑士剑路线](weapons/knightsword.md) 和 [最后的黎明](weapons/knightsword-80.md)。当前骑士剑上限为 +90，+80～+90 共用终阶模型；无需新增单件武器故事文件。

每份武器文档建议记录：

- 对应的路线、阶段、模型及当前配置 ID，避免故事与资产错配。
- 玩家可见的简短描述，以及一段铭文、誓言或转述。
- 这件武器独有的持有者、用途或流传经历。
- 它向玩家提供了哪一条新线索，又与哪件遗物互相印证或冲突。
- 记述的来源、立场与可信程度；玩家在何时适合接触这段文字。
- 作者备注：哪些是已确定设定，哪些是传说，哪些仍待讨论。

完整底稿末尾保留两把终阶武器的早期描述，单件 MD 保留早期框架与资产资料。三条路线的二十三阶中英描述与故事已在各自整合稿中保存并接入前端，后续修订以三份整合稿为准。
