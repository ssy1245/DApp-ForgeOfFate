# 三条武器路线与介绍索引

状态：三条路线双语词条索引 v0.4 · 更新日期：2026-10-28

本目录保存三条路线总览与 22 件进阶武器的资产、介绍框架。正式中文、英文名称沿用资产配置；当前玩家正文见[骑士剑九阶中英描述与故事](knightsword-stories.md)、[刺剑八阶中英描述与故事](rapier-stories.md)和[大剑六阶中英描述与故事](greatsword-stories.md)，共二十三阶，已接入前端阅读窗口。共用初始剑“余烬长剑 / Ember Longsword”纳入骑士剑整合稿，后续修订直接维护三份整合稿。

## 三条完全不同的叙事路线

| 路线 | 演化方向 | 核心气质 | 路线框架 |
|---|---|---|---|
| 熔核重剑 | 从普通铁匠武器，一步步异化成深渊龙骸、熔核与黑暗君主之剑。 | 黑暗、灾厄、压迫、君王 | [黑暗异化线](greatsword.md) |
| 骑士剑 | 从普通骑士佩剑，升级为王庭圣剑、黄金誓约与最后的献身之剑。 | 秩序、荣耀、誓约、牺牲 | [王庭誓约线](knightsword.md) |
| 刺剑 | 从普通女孩的习武、宫廷服役走向守护誓约，由绯翼骑士团护送幸存者与王国知识走向远方。 | 庇护、传承、优雅、坚毅 | [王室天使线](rapier.md) |

三条路线各自拥有叙事身份，外观演化应当服务于不同的故事方向。

## 阶段逻辑

### 熔核重剑：黑暗异化线

**凡铁 → 熔炉 → 龙骸 → 炉心 → 君王**

关键词：**黑暗 / 深渊 / 龙骸 / 熔核 / 君主**。

| 强化节点 | 阶段分类 |
|---|---|
| +10～+20 | 铁匠 / 熔炉阶段 |
| +30～+40 | 龙骸异化 / 熔核孕育阶段 |
| +50 | 炉心觉醒阶段 |
| +60 | 君王阶段 |

### 骑士剑：王庭誓约线

**骑士 → 王国 → 王庭 → 黄金誓约 → 最后的黎明**

关键词：**秩序 / 荣耀 / 王庭 / 誓约 / 牺牲**。当前正文不采用早期框架中的“黄金律法”。

| 强化节点 | 阶段分类 |
|---|---|
| +10～+20 | 骑士誓言阶段 |
| +30～+40 | 王国荣耀阶段 |
| +50～+60 | 王庭圣剑阶段 |
| +70 | 黄金巅峰阶段 |
| +80～+90 | 献身终局阶段 |

### 刺剑：王室天使线

**贵族 → 宫廷 → 王室 → 绯冠 → 天使**

关键词：**优雅 / 贵族 / 红宝石 / 誓约 / 羽翼**。

故事主线：**贵族身份 → 守护誓约 → 文明传承**。绯翼骑士团（Order of the Crimson Wing）由王室贵族与精锐女骑士组成，在黄金王庭覆灭时承担平民撤离、知识保存与下一代的保护。

| 叙事形态节点 | 主题 | 使命与视觉象征 |
|---|---|---|
| +5～+30 | 宫廷荣光 | 繁荣时期的贵族与女骑士佩剑；银钢、金饰、鸢尾花 |
| +40～+50 | 绯冠誓约 | 王室交付守护平民的使命；红宝石、王冠、王室盾徽 |
| +60～+70 | 天使守望 | 穿越黑暗、庇护幸存者、延续文明；银白羽翼、金色冠饰、赤红圣石 |

下表保留原有外观细分，三段叙事贯穿其中；+70 终阶延续至 +80。

| 强化节点 | 阶段分类 |
|---|---|
| +5～+20 | 贵族宫廷阶段 |
| +30～+40 | 王室誓约阶段 |
| +50 | 绯冠阶段 |
| +60 | 赤蔷誓约阶段 |
| +70 | 天使终局阶段 |

## 最终武器的对照关系

| 武器路线 | 最终中文名称 | 最终英文名称 | 最终象征 | 终极身份 |
|---|---|---|---|---|
| 熔核重剑 | [余烬君王](greatsword-60.md) | Sovereign of Ash | 黑暗君主、灾厄与深渊力量 | 黑暗的统治者之剑 |
| 骑士剑 | [最后的黎明](knightsword-80.md) | The Last Dawn | 骑士团牺牲、黄金誓约、最终希望 | 以献身换来希望的人类圣剑 |
| 刺剑 | [炽翼天使](rapier-70.md) | Seraph's Wing | 庇护与传承、幸存者与未来 | 为延续文明而守望的守护者圣器 |

熔核重剑代表“统治与力量”，骑士剑代表“荣耀与献身”，刺剑代表“庇护与传承”。主力骑士团为终结黑暗而牺牲，绯翼骑士团则必须活着，将希望带往远方。

## 当前等级与后续备注

- 熔核重剑最高 **+70**；+60～+70 使用“余烬君王 / Sovereign of Ash”。
- 骑士剑最高 **+90**；+80～+90 沿用“最后的黎明 / The Last Dawn”外观。
- 刺剑最高 **+80**；+70～+80 使用“炽翼天使 / Seraph's Wing”。

2026-10-26 已落实：+90 为骑士剑等级上限，沿用 +80「最后的黎明」的模型和参考图，不新增武器形态。

阶段分类中的“+5～+20”等范围指该组的形态节点；实际等级外观区间见各武器 MD。此处保存介绍与后续设计方向，强化规则仍以 [路线配置](../../3d/sword-branches.json) 和 [阶段配置](../../3d/sword-tiers.json) 为准。
