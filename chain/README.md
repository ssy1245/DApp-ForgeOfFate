## 已对齐的目标

自主完成“命运锻造所”DApp：在 **Sepolia** 上通过 **MetaMask** 铭刻武器 NFT，让 NFT 能用于质押产币，并支持玩家之间的交易。我们完成部署和演示，准备源码、部署资料、交易记录和视频。

- **充值**：调用充值合约，ETH 在同一笔成功交易中转入项目钱包；本地后端确认后增加游戏币。
- **NFT 用途**：锁定期间持续产币，取回后停止；已获得的币不用归还，累计产币暂不封顶。
- **运行方式**：本地后端按需启动，数据库和扫描进度持续保存；重新连接原 Sepolia 部署后补查事件。

产币速度、离线累计、取回条件、可质押数量以及充值价格仍以功能计划的待定表为准。

## 当前状态

最新开发安排：实际操作统一使用 Sepolia，NFT 等图片准备好后继续，充值暂缓。`npm start` 启动 Sepolia 游戏服务；`npm run deploy:console` 提供持久化的 MetaMask 部署工作台，当前仅提供无业务验证合约，等待最终确认后保存记录。真实节点只读检查已通过，实际部署仍需钱包确认。独立的旧本地数据保留，自动回归继续使用隔离测试环境。

现有完整游戏与 NFT 市场在本地 Hardhat 验收。已增加网络配置适配、环境数据库隔离、`npm run backend:sepolia` 独立后端入口和浏览器 / 数据库一致性回归；`.env.sepolia.example` 随源码提交，实际值填写在被 Git 忽略的 `.env.sepolia`。项目钱包同时用于部署和收款。独立 NFT 监听、版本化链上表、部署区块校验、停机补扫和同步面板已实现并通过本地链验证；Sepolia 业务合约实际部署、MetaMask 人工联调、ETH 充值、NFT 质押和资金账本仍待实现。
