## 已对齐的目标

自主完成“命运锻造所”DApp：在 **Sepolia** 上通过 **MetaMask** 铭刻武器 NFT，让 NFT 能用于质押产币，并支持玩家之间的交易。我们完成部署和演示，准备源码、部署资料、交易记录和视频。

- **充值**：调用充值合约，ETH 在同一笔成功交易中转入项目钱包；本地后端确认后增加游戏币。
- **NFT 用途**：锁定期间持续产币，取回后停止；已获得的币不用归还，累计产币暂不封顶。
- **运行方式**：本地后端按需启动，数据库和扫描进度持续保存；重新连接原 Sepolia 部署后补查事件。

产币速度、离线累计、取回条件、可质押数量以及充值价格仍以功能计划的待定表为准。
