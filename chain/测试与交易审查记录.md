## 本轮修复

| 问题 | 改动与验证 |
|---|---|
| 游戏把找到回执直接当作确认 | 后端检查规范链块哈希及最终确认边界；Sepolia 成功/失败均先等待 finalized。节点不支持时返回可重试错误，保留待处理记录 |
| sessionStorage 不能覆盖关闭标签页后恢复，切换环境还会丢记录 | 改为每笔交易独立 localStorage 记录，绑定网络/合约/部署/钱包，迁移旧记录；跨标签页更新；切换环境保留原记录 |
| 检查交易时只看执行状态，未验证返回身份 | 客户端校验 chain ID、deployment ID、交易哈希、发送人、最终状态；外来回执不能清掉原记录 |
| 异步拿铸造授权期间账号/钱包可能变化 | 发起前保存身份版本，拿到授权后再核验；授权请求带原档案标识，变化时阻止继续发送 |
| 已确认交易后的页面刷新失败与交易结果混在一起 | 分开处理确认结果和刷新错误，提示“结果已确认，数据刷新失败”，不误导为再次发送 |
| 铸造前查询 NFT 是否存在发生 RPC 异常时直接变成未处理错误 | 返回脱敏的 503；不签发不确定的授权，也不替换密钥 |
| 全量测试分散，复跑容易漏 | 增加 `npm test` 串行运行全部组、保留日志、失败仍运行其余组；任一失败则整体失败 |

## 交易与资源边界

### 链上合约

- EIP-712 签名绑定武器 ID、钱包、等级、URI、截止时间、网络、验证合约与部署标识。测试篡改字段、假签名、坏签名长度、错链、旧部署、截止秒和过期秒。
- 持有人方可挂牌/撤单；ERC-721 的操作授权不等同于挂牌权限。价格必须正数，购买锁定卖家和价格；少付、多付、旧价、自己买自己、已撤单/转走/成交均失败。
- 两名买家在关闭自动挖块后提交同一挂单，随后实际打包：只有一笔成功，卖家只增加一次收益。
- 买家拒收 NFT 时所有权、挂单、卖家收益、合约 ETH 原子回滚。拒绝安全铸造时不会消耗武器 ID，之后可以用原有效授权重试。
- 接收回调允许转移或重新挂牌；最终所有者和挂单保持回调后的真实结果，后发出的 `Forged`/`Purchased` 事件不能覆盖它们。索引器已有对应回归。
- 防重入覆盖接收回调再次买入、提现回调再次提现。提现接收失败时原收益保留，恢复接收后可提取；其他账户不能提现他人收益。
- 多次成交精确累加，卖家钱包到账等于成交总额扣去提现 Gas，不向游戏金币混入 ETH。

新增用例见 [MarketEdges.cjs](test/MarketEdges.cjs)。攻击接收方仅在测试内存编译，不加入生产部署构建。

### 服务器与数据库

- 资源扣除、发剑、回收、状态变更与幂等结果同事务；余额不足完整回滚，重复 key 同操作返回原结果、不同操作拒绝。
- 多请求回收或强化不能重复收益/扣费；新增封存与回收竞争测试保证同一武器只能进入一个终态。
- 保护符仅在挡住损毁时扣 1；阶段保护不扣；无保护符时在随机结算前拒绝，避免通过失败请求重掷。
- 测试涵盖路线门槛、最高等级、双成功跨上限、回收插值锚点、商店价格与余额不足、每日 UTC 边界、存取武器版本冲突。
- 钱包挑战绑定账号、会话、网站、网络与有效期，一次消费；钱包唯一性不区分地址大小写，账号和钱包的并发绑定均有测试。
- 铸造资格检查属于当前玩家、已封存、达到 +50、钱包已验签；签名密钥必须对应当前合约；RPC 不明、密钥缺失/错误、已有 NFT 均拒绝。
- 索引测试覆盖停机补扫、空块、重复事件、批次缩小、处理事务回滚、部署冲突、确认块变化暂停和恢复。

### 页面与部署

- 普通游戏覆盖真实服务请求、多标签页、旧响应、重试、账号切换、断线、仓库、保护符和窄屏双语布局。
- 新增交易恢复浏览器测试：刷新/新标签页、未最终确认的失败回执、错误钱包/哈希/部署、切换部署保留记录、重组导致回执暂失。
- 部署测试覆盖拒签、错误钱包/网络、重复意图、哈希恢复、重启、最终确认、发布中断、密钥/编译资料被改动及既有配置不覆盖。
- 独立链完整检查覆盖 API → 授权 → 合约 → 读取 → 监听 → 重启；当前普通游戏页面每种链上操作的实际钱包发送仍需进一步补测。

## 尚需处理的风险与限制

| 优先级 | 限制 | 后续处理 |
|---|---|---|
| P0 | 加速/取消产生新哈希，原交易可能一直显示待处理；广播后未收到哈希无法自动找回 | 保存交易意图与 nonce，核验替换或取消证据，补恢复入口和发送阶段测试 |
| P0 | 没有真实 Sepolia NFT 合约与双钱包验收证据 | 按计划实际部署、铸造、买卖、提现与重启恢复 |
| P1 | `operations` 不是独立游戏币流水；长期不限额奖励会触及整数/前端精度 | 先做账本与金额表示，再做质押奖励 |
| 后续 | NFT 列表用最新块号分页而非块哈希；旧列表可能暂时过期 | 强化快照一致性；当前成交仍由合约检查卖家/价格/归属 |
| 后续 | allTokens 全量枚举和逐 token RPC、SQLite 读请求也取写锁、主要游戏表索引不足 | 面向规模时优化查询/分页/索引，目前仅本机演示 |
| 后续 | 提现无独立事件、授权密钥不可轮换、元数据图片依赖外部托管 | 明确演示边界；如改合约须另做部署迁移，不静默替换当前计划 |
| 后续 | 无账号找回/限流和公网 HTTPS 会话方案，依赖与包体有警告 | 公网发布或真实资产场景前专项硬化 |

目前的课程版本可继续按计划收尾，不能据此宣称生产资金安全已经得到保证。充值和 NFT 换回武器保持暂缓；质押尚未实施，不包含在“已通过”的业务范围中。
