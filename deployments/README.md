# 公开部署配置

[`sepolia-demo.json`](sepolia-demo.json) 是 2026-10-31 完成部署的 `ForgeOfFate` NFT / ETH 市场清单，网络为 Ethereum Sepolia（`11155111`）。它从本机已确认的部署记录按公开字段导出，供老师连接同一市场使用。

安装、配置 RPC、导入、游戏与监听启动步骤见[项目 README](../README.md#快速启动)。程序实际读取 `.local/sepolia/deployment.json`，不会自动读取本目录；不要把已有运行环境的清单直接覆盖为另一份部署。

| 内容 | 用途 |
|---|---|
| 合约地址、chain ID、ABI | 后端读取合约，前端调用交易 |
| `deploymentId`、`mintSigner`、构造参数 | 核对部署和铸造授权身份；均是公开信息 |
| 部署交易、部署区块和区块哈希 | 核对部署回执，确定监听起点 |
| 创世区块、代码、编译信息指纹 | 核对链与合约身份，发现清单不匹配 |
| 确认策略、记录时间 | 说明 Sepolia 使用最终确认边界 |

本目录不包含 RPC 连接地址、服务商 API 密钥、`mint-key` 私钥、钱包秘密或游戏数据库。复制公开清单不会授予新 NFT 的铸造权限；要独立复现铸造，按 README 在自己的新目录部署合约。

当前本目录只提供已最终确认的 NFT / ETH 市场清单。真实铭刻和双钱包购买已跑通；质押部署交易已提交、仍待最终确认，暂不发布质押清单。确认后从 `staking-deployment.json` 筛选公开字段，核对 `nftAddress` / `nftDeploymentId` 与本目录 NFT 清单一致，再增加公开质押清单及导入说明。不要复制包含计划、数据库、凭据的整个运行目录。充值未实现。

每日游戏金币费率属于老师的服务器配置，不属于合约 ABI。本次测试采用 `FORGE_STAKING_COINS_PER_DAY=1000`；模板保留 `0`，老师启用前需主动设置。公开源码验证与完整验收进度见[链上计划](../chain/链上功能与开发计划.md)。
