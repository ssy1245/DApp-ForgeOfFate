大剑六阶的现行[中英武器描述与故事](../assets/stories/weapons/greatsword-stories.md) 已接入前端。从矿镇守路、控矿与龙骸异化逐渐走向强征、焚城和围都，后半程以暴君视角回应石桥之战、渡口夜袭与最后的白剑；+60～+70 共用余烬君王的终阶故事。三条路线的共同事件保持一致，最后一战的胜负未写定。

放入 **`assets/3d/`** 或其子文件夹；剑的 `model` 配置填写相对此目录的路径（省略 `.glb`）：

- `sword.glb`：已接入，基础长剑。
- `KnightSword/+10KnightSword.glb`～`+80KnightSword.glb`：骑士剑八阶模型，分别对应 +10 / +20 / +30 / +40 / +50 / +60 / +70 / +80；模型和参考图统一采用 `+等级KnightSword` 命名。
- `rapier/+5rapier.glb`～`+70rapier.glb`：刺剑 +5 / +10 / +20 / +30 / +40 / +50 / +60 / +70 八阶独立模型，已同步用户改名后的路径。参考图为 `assets/reference_page/Rapier/+等级rapier.png`。
- 巨剑 `GreatSword/+10GreatSword.glb`～`+60GreatSword.glb` 六阶独立模型及参考图已全部接入；+40 为熔脉龙骸、+50 为深渊炉心、+60 为余烬君王，终阶外观保持到 +70。+10 起可主动选择巨剑路线。
- `hammer.glb`：已接入，锻造锤。
- `anvil.glb`：可选，铁砧目前使用程序生成模型。

详细规格与生成描述见 [资产需求](../assets/3d/README.md)。剑、锤、铁砧缺失或加载失败时自动使用占位模型；地面、石质底座、炉火、矿石、材料箱、余烬由程序生成。加入 GLB 后刷新页面即可；保存武器 JSON 配置会自动重载开发后端，待重载完成后刷新页面。构建时会按子文件夹结构把配置引用的 GLB 复制到前端产物，支持路径中的空格和 `+`。

## 中英文界面

顶部可选择 **中文 / English**。首次打开默认中文；选择保存在当前浏览器的 `forge:language` 中，刷新和再次打开后继续使用。切换即时生效，不会重置资源、选中的武器、当前页面或操作状态。

两套文案覆盖工坊、背包、NFT 市场、账号登录 / 注册、测试菜单、每日领取、资源与费用、确认弹窗、交易等待状态，以及服务端返回的操作结果和错误。工坊内的领剑处招牌、三维视图提示、武器状态面板和图片替代文字也随语言更新。英文界面已调整长文案换行和窄屏悬浮面板位置；资源栏在窄屏完整显示大额金币。

中文保留现有文案和武器卡片的英文副标题；英文使用正式英文武器名、路线名、品质和状态。用户名、钱包地址及交易编号保留原文。语言只影响显示，不改变武器 ID、资源规则、接口品质值或已铸造 NFT 的元数据。

翻译集中在 `frontend/src/locales/en.json`；中文原文作为索引，包含带数字的提示模板。`locale.ts` 处理模板和浏览器偏好，`i18n.tsx` 提供共享语言状态。新增界面文字或后端提示时需同步英文条目。后端响应保留原格式，客户端按当前语言展示，已显示的提示也可即时切换。

运行 `npm run test:i18n -w frontend` 检查源码新增文案是否有英文对应、翻译参数、动态提示、语言偏好、23 个武器阶段的普通 / NFT 卡片、英文测试菜单、金币数额、游戏内确认弹窗和初始工坊。测试菜单的英文选项继续发送原有品质值，保证强化和刷剑接口兼容。回收、封存、路线锁定和转赠采用游戏内深色确认框，确认 / 取消按钮随语言更新，取消不会提交操作。

2026-10-28 界面整理：保留资源、仓库存取、加热与敲击等常用操作，压缩顶部重复提示；测试菜单移到主要游玩区域下方并默认收起，本次浏览器会话记住开合状态。路线规则、消耗说明和视角设置按需展开，武器状态面板默认收起，熔炉里的武器仍能直接取回。桌面和 360 / 390 像素窄屏均检查中英文布局、仓库弹窗和键盘操作。 后续按试玩反馈移除左侧重复领剑浮层和屏幕 WASD 按钮，入口只保留简短提示；键盘 WASD / E / Esc 继续有效。领剑额度在场景剑架招牌显示，靠近剑架或切换环绕模式时可使用底部领剑按钮。仓库箱与招牌靠左墙摆放，避开中央过道。

## 工坊视角与拿放

工坊外侧已围成铁匠铺：石砌墙裙、灰泥墙面、木柱与斜撑、横梁屋顶、铁格窗、厚木门、壁灯和石板地面均由程序生成。第一人称显示完整围墙和屋顶；环绕模式隐藏靠近镜头的墙及屋顶，便于查看内部。门目前为场景装饰，移动范围仍限制在铺内。熔炉位于左后墙角、砧台沿后墙、三个展示柜朝内沿右墙排列，材料箱和矿石放在左墙边，中央区域留作通道；设备位置、碰撞和锤击落点共用布局配置。

- **环绕查看**：拖动场景旋转视角，滚轮缩放；点击长剑或使用画面下方的按钮拿放。
- **第一人称**：点击三维画面进入并隐藏 / 锁定鼠标，用 WASD 前后左右移动；鼠标相对移动直接控制转头，鼠标停止则视角停止。走近锻造台或展示柜后按 E 拿放。按 Esc 退出操控并释放鼠标，键盘立即停止作用；再次点击画面继续。内置预览不允许鼠标锁定时自动使用窗口内相对转头并隐藏鼠标；移出三维画面不再暂停，在页面其他区域移动鼠标仍可转头。按 Esc、切换窗口 / 标签页或点击工坊以外的页面区域才退出操控并恢复鼠标；编辑输入框也会退出。完整的无限相对移动和阻止鼠标离开窗口依赖浏览器 Pointer Lock 支持，建议在 Chrome / Edge 中体验，CSS 隐藏鼠标不能替代真正锁定。
- 画面右上方可调节 **视角灵敏度 0.2×–2.5×**，设置保存在本浏览器。鼠标锁定期间先按 Esc，再操作灵敏度或页面按钮。环绕模式的旋转速度也使用该设置。
- 窄屏触摸设备可使用画面中的 W/A/S/D 按钮移动，手指拖动画面转头。
- **展开**：放大工坊；再次点击“收起”返回；Esc 只暂停操控，不收起画面。**复位**恢复当前模式的初始视角。
- 第一人称下，剑放在铁砧且玩家靠近时自动取出锻造锤；拿起剑或离开时自动收起。锤子不再悬浮在工坊中，已接入正式 GLB 模型与取用过渡。
- 长剑可在锻造台、手持与展示柜之间切换。家具周围有简单碰撞限制。展示柜已增加到三个，沿右墙朝内排列；每柜已加宽、加深，并进一步压低底座、抬高顶部，内部净高比三柜初版增加约 43%；现有剑保持原展示大小，上下预留更多空间。柜脚贴地、柜顶低于横梁，顶部暖光及底部补光随柜体调整。后续超长模型会按相同比例适配，至少保留 10% 的上下总余量。每柜可独立放一把背包武器，切换当前武器后其余柜内展示保留，并各自使用对应路线和等级的模型；已占用柜位不能覆盖。环绕模式点击柜子、第一人称靠近后按 E，可直接取出柜内武器并切换为当前武器。巨剑在铁砧上按完整尺寸显示，手持和炉内按可用空间等比适配，展示柜沿用净高约束。

这是场景展示交互，三个柜位及摆放位置仅保存在当前场景中；切换页面或刷新会重置，不会出售、转移或改变背包武器的链上归属。第一人称目前没有人物身体或手部动画。

## 武器仓库与继续锻造

工坊同时取用一把未封存武器，取用状态保存在数据库。游戏无需连接钱包即可使用仓库，也不会发起链上交易或扣除资源。

**游玩场景内也有可交互的仓库**：左墙边带固定招牌的“武器仓库”木箱可以在环绕模式下点击；第一人称靠近后按 **E** 打开。画面顶部的 **仓库** 按钮可随时打开同一个面板，展开场景和手机屏幕也可使用。面板直接显示武器图片、等级、热量、保护进度和当前取用状态，可以存入当前武器或取出另一把，不需要离开游玩画面。取出后点“继续锻造”或“返回游玩”关闭面板。

打开面板会暂停移动、敲击并释放鼠标，避免操作仓库时误触锻造；按 Esc 或“返回游玩”关闭，再点击场景继续操控。列表随服务器同步更新，失效或被删除的武器会移除，封存武器显示为不可取用。存取失败的提示直接显示在面板中。

1. 在锻造画面上方点击 **存入仓库**，当前武器离开手持、铁砧、熔炉或展示柜，工坊变为空闲。不会自动换成背包里的下一把。
2. 点击 **打开武器仓库**，找到另一把武器，点击 **取出并继续锻造**。武器回到铁砧，可以继续加热和敲击。
3. 也可用右侧 **从仓库取用** 直接选另一把；原工坊武器自动存回仓库。等级、路线、剩余热量、加热完成时间和阶段保护进度都保留。
4. 刷新页面、重登或重启服务器后，保持原来的取用武器或空闲状态。场景中的手持姿势、炉内位置和展示柜摆放仍是临时视觉状态；重新取出的武器通常从铁砧开始。如果上次加热还未结束，会回到熔炉继续等待原定完成时间，不重新扣材料，也不能提前敲击。

工坊为空时，领取、锻造或购买的新武器会自动放到铁砧；工坊已有武器时，新武器进入仓库，不替换当前武器。旧存档第一次升级到此版本时，工坊为空，原有武器和进度都保留在仓库，手动取出即可。封存武器保留在仓库中供铭刻 NFT，但不能取出继续锻造。

回收、损毁或封存当前武器时，后台同步清空工坊。若数据库中的武器被删除、转给其他玩家或改为不可锻造状态，页面在下一次成功同步时清理对应的手持、炉内和展示柜模型。前台每 5 秒查询一次，重新聚焦窗口也会查询；这不是瞬时推送。后台在每次加热和敲击时重新核对所有者、状态及当前工坊选择，旧页面不能继续消费失效武器。断开服务时暂停操作并隐藏旧武器模型，恢复后按数据库状态显示。

这套仓库是链下武器存取，与未来的 NFT 质押、链上转移分别处理。自动化检查及复现方法见[本地测试与页面数据一致性](../chain/本地测试与页面数据一致性.md)。

## 熔炉、敲击与场景概率面板

熔炉采用加宽、加高的程序生成砖砌拱炉，包含烟囱、炉台、金属箍与炭床；另加高台底座，炉台工作面约 1.23，与砧台约 1.21 齐平，炉口进一步横向加宽，为大剑预留空间。砧台采用倒角台面、收腰铸铁结构、固定螺栓与金属铭牌细节。火焰使用多层程序着色，火舌根部固定在炭床，顶部随气流左右摇摆并卷曲，各层错开伸缩、明暗与宽度变化，另有炉光闪动和上升余烬；炉体碰撞与炉口交互点同步配置。

1. 领取材料，选择每天赠送的初级余烬长剑（也可消耗材料锻造）；游戏无需钱包即可开始。
2. 使用“送入熔炉”按钮，或拿起武器、走到熔炉按 E / 点击“放入熔炉”，开始加热。材料不足时，加热按钮、工坊底部和收起状态的武器面板都会明确提示所需材料与当前剩余数量；补充材料后可继续加热。
3. 初始加热时间为 3 秒，每炉消耗 2 铁块，提供 5 次敲击热量。加热过程中不能敲击；时间结束后取回铁砧。
4. 铁砧前可按鼠标左键或空格敲击；Esc 暂停后也可使用场景面板按钮。每锤消耗当前路线要求的铁块，由后端随机结算四种结果。界面和场景面板显示下一锤消耗，铁块不足时无法敲击。
5. 每敲满五锤才需再次加热，不按等待时间自动冷却；离开铁砧或拿放不会消耗次数。初始剑达到 +5 后可主动选择突变为精铁刺剑，+10 后可选择巨剑，也可继续骑士剑路线；默认骑士剑达到目标门槛后可免费选择刺剑或巨剑，但等级分别重置为 +5 / +10，不继承高等级。确认框显示重置前后的等级；选定后不能互换或转回骑士剑，降级也不解除锁定。骑士剑按 +0 / +10 / +20 / +30 / +40 / +50 / +60 / +70 / +80 升级，刺剑按 +5 / +10 / +20 / +30 / +40 / +50 / +60 / +70 依次使用精铁刺剑、银锋刺剑、宫廷细剑、鸢尾刺剑、王室誓剑、绯冠刺剑、赤蔷誓约、炽翼天使模型。巨剑按 +10 / +20 / +30 / +40 / +50 / +60 使用铁匠大剑、烬炉大剑、渊角龙骸、熔脉龙骸、深渊炉心、余烬君王六个阶段，场景长度从 4.2 增长至 5.4。共 23 套独立剑模型均已接入；骑士剑 +70 为黄金誓约、+80 为最后的黎明，均已接入；骑士剑 +80～+90 沿用最后的黎明外观，巨剑 +60～+70、刺剑 +70～+80 保持最终外观。刺剑降级到 +5 以下、巨剑降到 +10 以下恢复共用初始剑，剑种选择仍保留。三条路线的名称、模型和长度按 `branch` 统一配置在 `assets/3d/sword-tiers.json`，详见 `assets/3d/README.md`。NFT 门槛为最终形态：骑士剑 +80、刺剑 +70、巨剑 +60。

场景内武器面板可展开 / 收起，桌面和窄屏均默认收起；收起时仍可在加热完成后取回铁砧，带五格热量指示；进入操控提示改为底部轻提示。面板显示剑名、等级、冷却／加热／烧红状态、剩余热量、保护符、阶段保护以及下一锤各结果的目标等级和最终概率。锤子以握柄为旋转支点，先蓄力再快速下砸，由金属锤头接触剑身；接触短暂停顿后回弹，火星与闪光在同一落点、同一时刻触发，动作结束后才能开始下一锤。热金属发光和损毁碎片用于反馈；损毁后当前剑从背包及场景移除。

### 保护符与 Q 快捷键

2026-10-30 更新：在锻造工坊按 **Q** 开启 / 取消保护，也可点击保护符选项。开启不立即扣符；只有本来会损毁的一锤被保护符挡住，才扣除 **1 张**，武器等级不变，随后自动关闭保护。普通升级、大成功和降级均不扣符，开关保持待命；阶段免损毁优先生效，不扣符，之前开启的保护在阶段结束后继续待命。

保护不阻止降级，敲击仍正常消耗铁块和热量。没有保护符不能启用，后端在抽取结果前检查库存；请求重试不会重复扣符。切换工坊武器、切换游戏账号、刷新页面或用掉最后一张后会关闭待命状态。输入文字、打开弹窗、处理操作期间以及仓库 / 市场页面不响应 Q；长按只切换一次。场景面板即使收起也显示保护符复选框、“已开启 / 未开启”和“剩余 X 张”，按 Q 或点击复选框都同步勾选状态；实际挡住损毁后自动取消勾选，数量随服务端库存更新。阶段保护单独提示且不耗符；第一人称和环绕模式均可使用。

+0 基础剑回收仍为 1,000 金币，低于购买成本，不能直接买入再回收获利。每日免费剑仍可正常回收。已有武器保留原等级及品质，已有金币余额、三条路线回收价格、强化消耗、概率、保护符和每日补给沿用现有规则。测试 ETH 充值已实现，待完成 Sepolia 部署与真实到账验收；临时兑换比例和运行步骤见根 README。

按当前强化概率，从 +0 起、首次达到门槛即选择目标路线、全程免损毁，并计入大成功、降级与保护后不变，预计到满级需约 106／144／125 锤（巨剑 +70／骑士剑 +90／刺剑 +80）；铁块含加热约 **730／610／420**。加热按平均每 5 锤一炉估算，最后一炉未用完的热量会带来少量差异。这是比较路线用的期望值，不含新剑锻造、保护符或损毁重造成本，也不代表自然冒险必然花这些铁块。巨剑上限提高至 +70 后，预计总铁块投入重新高于骑士剑与刺剑；后续继续结合损毁、保护符与每日供给进行试玩平衡。

刺剑与巨剑的选择是一次性决定：前端选择前提示，后端拒绝转回骑士剑或改走另一条特殊路线；已有刺剑／巨剑也适用，重登、降级和后端重启不解除锁定。默认骑士剑达到解锁门槛即可选定路线，转刺剑重置为 +5、转巨剑重置为 +10；高等级不能跨路线继承。同一路线重复请求不重置等级，旧确认页面的等级或路线已经变化时会拒绝操作。热量、保护进度和资源保持不变；上述总量比较按最早选择路线计算。

每日领取按 UTC 零点重置，未消耗资源与武器暂时累积保留。价格、发放数量和损毁率均集中配置，后续需试玩平衡。
